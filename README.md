# Gamepad-esp32-proxy
Проект ретранслятора данных от геймпада на приемник ПК

---

### PC-Script
Питон скрипт для чтения данных с COM порта,
данные с которого посылаются в заранее созданный виртуальный геймпад

### Esp32-firmware
Прошивка для МК **ESP32**

В процессе работы устанавливает соединение с геймпадом и 
начинает транслировать приходящие данные в COM порт.
